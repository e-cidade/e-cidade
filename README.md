# e-Cidade

O **e-Cidade** é um software livre de gestão pública municipal criado
originalmente pela **DBSeller**. Ao longo de sua história, diferentes
organizações, órgãos públicos, empresas, comunidades e profissionais passaram a
desenvolver, adaptar e manter diferentes linhas do projeto.

Este repositório é o ponto de entrada comunitário da organização
[`e-cidade`](https://github.com/e-cidade). Ele não contém uma distribuição do
software: seu objetivo é ajudar a entender o ecossistema, encontrar os projetos
existentes e facilitar a colaboração entre seus participantes.

## Onde está o código?

O desenvolvimento do e-Cidade acontece hoje em diferentes repositórios
mantidos por participantes do ecossistema.

A organização `e-cidade` busca dar visibilidade a essas linhas, registrar suas
origens e mantenedores e facilitar a descoberta de onde cada desenvolvimento
acontece.

Alguns repositórios são mantidos diretamente por seus respectivos mantenedores;
outros podem aparecer nesta organização como **mirrors**, identificados
explicitamente e sincronizados com suas origens.

Veja o [mapa do ecossistema](docs/ecosystem.md).

## Como participar

Você pode:

- contribuir diretamente com uma das linhas de desenvolvimento existentes;
- abrir uma Issue neste repositório comunitário quando não souber onde uma contribuição deve ser feita;
- propor documentação ou melhorias para a estrutura comunitária;
- apresentar um projeto relacionado ao e-Cidade;
- propor a transferência de um repositório ou projeto para manutenção
  comunitária na organização `e-cidade`.

Veja [como contribuir](docs/contributing.md).

## Governança

A organização busca ser um espaço compartilhado por diferentes participantes do
ecossistema, preservando a autonomia e a autoria dos projetos que o compõem.

As regras e processos comunitários serão documentados progressivamente em
[governança](docs/governance.md).

## Transferência de projetos

Projetos relacionados ao e-Cidade podem ser propostos para transferência à
organização quando fizer sentido mantê-los de forma comunitária.

Veja [transferência de projetos](docs/repository-transfer.md).
